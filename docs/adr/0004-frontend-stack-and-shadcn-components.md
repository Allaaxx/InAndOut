# 4. Interface Web com Shadcn UI e Blocos de Dashboard

O frontend da aplicação InAndOut será construído com React 19, Vite, Tailwind CSS e a biblioteca de componentes aberta shadcn/ui. Serão utilizados os blocos oficiais gratuitos de Dashboard (Stat Cards, Sidebar responsiva e Shadcn Charts sobre Recharts) e componentes de alta produtividade como `InputOTP` para entrada de PIN/RA, `DataTable` para listagem de ocorrências na Coordenação, `Sonner` para notificações reativas via Socket.io e `Dialog/Sheet` para desfechos de atendimento.
